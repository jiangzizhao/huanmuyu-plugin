# Huanmuyu（换母语）

[English README](README.md)

换母语是装在 [Obsidian](https://obsidian.md) 里的桌面端语言学习插件：打卡日历、词卡、间隔复习、分级阅读、朗读、造句练习和生词库集中在一个学习流程里。界面、词义和例句对照主要面向中文学习者。

## 使用条件与付费说明

- 需要 Obsidian 桌面版 1.4.0 或更新版本，**不支持手机版**。
- 学习功能需要**付费的 100 天授权**。在 `monoi.cn` 公众号购买后，把收到的密钥填进插件，在线验证；授权绑定一台设备。
- 密钥验证、缺失学习资源和下文列出的语音操作需要联网。英语和日语自然声还需要本机存储空间与运行模型所需的电脑资源。

插件源码采用 MIT 许可，不代表在线服务与付费授权免费。授权到期后，已保存的内容和进度仍在库里；继续使用受授权控制的学习功能，需要有效授权。

## 安装与开始学习

1. 从本仓库已发布的 release 下载 `main.js`、`manifest.json`、`styles.css`，直接放进 `你的库/.obsidian/plugins/huanmuyu/`。
2. 打开 Obsidian 的「设置 → 第三方插件」，启用 Huanmuyu；如果新安装的插件暂未出现，可重新启动 Obsidian。
3. 在插件设置中粘贴付费密钥并点击验证，通过日历图标或插件命令打开学习日历。
4. 选择语言，完成需要的分级测试，再点日期开始学习。

如果你的社区插件目录里已能找到 Huanmuyu，也可以通过该目录安装和更新；手动安装不依赖市场上架状态。

[安装与使用图文教程](https://api.monoi.cn/nbp/native/guide)

## 内容、进度与朗读

- 支持英、日、韩、法、中、西班牙、阿拉伯语学习轨道。内置英语、日语、韩语分级内容，也可以导入自己的单词和 Markdown 文章。
- 韩语按 TOPIK 1–6 分级；日语按 N5–N1 方向分级，首次需要完成测试推荐起点，词义与例句配中文对照。
- 学习进度、复习记录、导入材料和生词库保存在你的库里；插件本身不是云同步服务。
- 英语、日语自然声在资源缓存后由本机合成。英语提供男女声；日语固定使用界面标注的 02 号女声。
- 选定英语或日语后，插件可以在后台自动准备语音资源；下次启动 Obsidian 且已选定该语言时也可能准备，点击朗读时缺失的资源同样会自动准备。**不需要手动安装单独的声音包**。首次缓存和模型启动需要联网与等待，后续优先复用已有资源。
- 韩语自然声由服务器返回音频后缓存到本机，具体发送内容见下表。其他语言及回退朗读使用电脑的语音能力；声音是否可用、系统是否另外联网，取决于操作系统和所选声音。

## 网络使用与隐私

下表对应本版本客户端实际请求。下载服务会收到 IP 地址等正常连接信息。配置自定义授权地址后，验证请求会发送到该地址；如果地址以 `/validate` 结尾，韩语语音会由它派生 `/tts-v2` 地址，否则使用下表默认地址。

| 触发时机 | 地址与请求 | 发送内容及用途 |
|---|---|---|
| 在设置或未解锁的日历里点击验证密钥 | 默认 `POST https://api.monoi.cn/nbp/native/validate` | 密钥、本机随机生成的设备 ID（`deviceId`），用于验证授权与设备绑定。 |
| 英语读音标注需要尚未缓存的词典 | `GET https://api.monoi.cn/nbp/native/ipa` | 请求英语音标词典，不携带正在阅读的文章；下载后缓存到本机。 |
| 当批单词的本地词卡不完整 | `GET https://api.monoi.cn/nbp/native/cards` | 查询参数包含密钥、设备 ID、语言与需要的单词；可能用于**英语、日语、韩语**缺失词义或例句的补全。 |
| 准备英语或日语本地语音，且模型文件缺失 | `https://huggingface.co/onnx-community/Kokoro-82M-v1.0-ONNX/resolve/main/` 下的文件 | 下载 `config.json`、分词配置及 `onnx/model_quantized.onnx`。模型下载请求不包含朗读文字或插件密钥，文件缓存在插件目录。 |
| 日语本地语音需要读音处理资源 | `https://cdn.jsdelivr.net/npm/kokoro-js-jp@0.2.0/dist/` 下的文件 | 下载 Open JTalk 词典、语音文件、JavaScript worker/包装代码与 WASM；缓存前校验文件大小和 SHA-256。这些下载请求不包含朗读文字或插件密钥。 |
| 朗读本机尚未缓存音频的韩语文字 | 默认 `POST https://api.monoi.cn/nbp/native/tts-v2` | 发送密钥、设备 ID（`device`）、`language: "ko-KR"` 及待合成的 `text`。**韩语朗读文字会发送给服务器**；如果你选择朗读文章或导入内容，其中相应文字也会发送。客户端整理空白并将每次请求限制为 500 字符，返回的音频缓存后复用。 |
| 本地英语或日语语音运行时 | 本机 `http://127.0.0.1:<随机端口>/` | 仅监听回环地址，把插件 `offline-tts` 目录的运行时、模型和音色资源提供给本机渲染器；不把库里的笔记作为网页提供，也不将它们发送到外部主机。插件卸载时关闭监听。 |

客户端没有整库上传、进度云备份或生词库云同步功能。但这不等于“任何学习文字都不会离开电脑”：词卡补全会发送所需单词，韩语朗读会发送待读文字。英语、日语合成走本机渲染器；下载模型与把文字发送到远程合成是两回事。

本文说明客户端行为，不代替服务器运营者的数据保留政策，也不承诺操作系统语音或第三方下载服务的隐私行为。不希望发送到语音服务的文字，请不要用远程韩语朗读处理。不要公开你的密钥或未遮盖的 `data.json`。

## 已安装用户如何更新

1. 先备份 Obsidian 库和 `你的库/.obsidian/plugins/huanmuyu/data.json`。
2. 禁用 Huanmuyu，只用新版的 **`main.js`、`manifest.json`、`styles.css`** 替换对应文件。
3. 保留 `data.json`、学习内容目录和已有语音缓存，不要为更新而删除整个插件文件夹。
4. 重新启用插件，必要时重启 Obsidian；检查版本、密钥状态、所选语言和原学习进度。

仅替换安装文件不需要重新购买密钥；原授权是否有效仍按原权益判断。

## 常见问题

- **密钥验证失败：**检查完整密钥、网络和设备绑定。不要把密钥发到公开 issue；可按图文教程联系公众号核对订单或绑定。
- **首次朗读慢或失败：**等待资源下载和本机初始化，确认能访问上述下载服务且本机空间足够。语音缓存不是需要另外购买的声音包。
- **日语或韩语某级内容为空：**检查语言、等级和日语测试完成情况，先按教程排查，不要先删除学习文件。

## 从源码构建

```bash
npm install
npm run build
```

入口是 `main.ts`，由 esbuild 生成 `main.js`。源码还包括分级词汇、阅读模块、`styles.css` 与 `manifest.json`。分发构建产物时，请保留第三方语音资源的许可与声明。
